Apna GitHub URL daal kar "Auto-Analyze Repo" par click karein. Ye automatically README, main code aur technologies ko scan kar lega.

College format chunein ya agar college ne apna Word sample format diya hai to direct upload karein.

        


        

          
4. Screenshots & Diagrams

          
Mermaid architecture diagrams auto-generate hote hain, aur screenshots proper captions ke sath lagte hain.

        


        

          
5. Prompt Se Changes (Prompt Revision)

          
Report banne ke baad niche AI Prompt bar me kuch bhi likhein — jaise "Chapter 4 me CNN equations add karo" ya "Roll number change karo" — AI turant update karega!

        


        

          
6. Download Final .docx & PDF

          
"Download University .docx" par click karke college-compliant Word document save karein ya direct print karein.
